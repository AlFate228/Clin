# Сайт химчистки авто — Каспийск

Готовый MVP: каталог услуг, корзина, календарь свободных/занятых дат, форма заявки и Telegram-уведомления. Управление занятыми датами — через Telegram-бота.

## 1. Что нужно заменить
1. Положите ваш логотип в `public/logo.png`.
2. При желании поменяйте тексты/услуги в `app/page.tsx` в массиве `SERVICES`.

## 2. Создать Telegram-бота
1. Откройте Telegram и найдите `@BotFather`.
2. `/newbot` → задайте имя и username → получите токен.
3. Создайте Telegram-группу, куда должны приходить заявки, и добавьте туда бота.
4. Узнайте ID группы (для супергруппы обычно начинается с `-100`). Можно временно написать сообщение в группу и посмотреть updates через Telegram Bot API.
5. Узнайте Telegram ID каждого мойщика, которому разрешено управлять календарём. Запишите их через запятую в `TELEGRAM_ADMIN_IDS`.

## 3. База данных
Проще всего на Vercel создать Neon Postgres через Marketplace/Integrations.
После создания скопируйте `DATABASE_URL` в Environment Variables проекта Vercel. Таблицы создаются автоматически при первом обращении к календарю или боту.

## 4. Переменные Vercel
Добавьте:
- `DATABASE_URL`
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `TELEGRAM_ADMIN_IDS`
- `NEXT_PUBLIC_CITY=Каспийск`

## 5. Загрузка на GitHub
Создайте новый приватный или публичный репозиторий и загрузите все файлы проекта.

Локально:
```bash
npm install
npm run dev
```
Откройте http://localhost:3000.

## 6. Деплой на Vercel
1. Войдите в Vercel.
2. `Add New → Project`.
3. Импортируйте GitHub-репозиторий.
4. Framework Preset: Next.js.
5. Добавьте Environment Variables из пункта 4.
6. Нажмите Deploy.

## 7. Подключить Telegram webhook
После деплоя получите адрес проекта, например `https://ваш-проект.vercel.app`.
Откройте в браузере:
`https://api.telegram.org/botВАШ_ТОКЕН/setWebhook?url=https://ваш-проект.vercel.app/api/telegram`

Если Telegram вернул `"ok":true`, бот подключён.

## 8. Управление календарём
Мойщики с ID из `TELEGRAM_ADMIN_IDS` могут писать боту:

`/занять 2026-10-01`

`/освободить 2026-10-01`

После этого сайт подтянет календарь из базы. В текущей версии занятая дата блокируется для всех заявок на этот день.

## 9. Как приходит заявка
Клиент выбирает несколько услуг → дату → время → вводит имя, телефон, автомобиль, госномер и дополнительные пожелания. После отправки данные записываются в БД и сразу отправляются в Telegram-группу.

## Важно для продакшена
Перед рекламой рекомендуется добавить: антиспам/rate-limit, проверку телефона, защиту webhook секретом, отдельные слоты по каждому мойщику, возможность подтверждать/отменять заявку и страницу администратора. Сейчас это аккуратный рабочий MVP для запуска.
